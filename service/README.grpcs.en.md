This directory is a webman gRPC **client** project (contract stubs are in `generated/`, generated by `scripts/gen-contracts.sh`).

## Dependencies

- Composer packages: `grpc/grpc` (PHP client library), `google/protobuf` (message runtime) — already added to `composer.json`.
- PHP extensions: `grpc` (required; client connections depend on the C extension). The `google/protobuf` extension is optional (prefer the extension if available, otherwise use the Composer package).

## Installing the grpc extension

```bash
php -m | grep grpc || sudo pecl install grpc   # php_dir 属 root，pecl 需 sudo
```

After installing, confirm `php -i | grep grpc` shows `grpc support => enabled`.

Current dev machine (2026-08-17): Composer packages are installed (grpc/grpc 1.82, google/protobuf 5.35), **the grpc extension is not installed** (pecl has no write permission, sudo requires a password). It must be installed before gRPC can run locally; CI (T10) installs it via shivammathur/setup-php's `extensions: grpc`.

## Notes

In this repository, `composer require` triggers a fatal duplicate class loading error in the `erikwang2013/security-php` plugin (Installer.php in vendor is loaded once by the plugin mechanism and once by autoload); add `--no-plugins` to work around it:

```bash
composer require grpc/grpc google/protobuf --no-interaction --no-plugins
```

## Liveness probe script

`php scripts/probe_ping.php` (provided by T5) issues `InfraService.Ping` against infrastructure's `127.0.0.1:50051`.
