## 第一轮修复（8 项）

### 1. bee_kv — 不必要的 `mut` 关键字（编译警告）

**文件：** `crates/bee_kv/src/lib.rs:129,136,145,158`
**严重程度：** 低

`StubKvStore` 的所有方法都通过 `&self` 调用（内部用 Mutex），测试中的 `let mut store` 不需要 `mut`。已改为 `let store`。

### 2. bee_router — `into_response()` 中的 `unwrap()` 可能导致 panic

**文件：** `crates/bee_router/src/context.rs:119`
**严重程度：** 中

`builder.body(...).unwrap()` — 虽然 header 值由内部构造不会包含非法字符，但违反「库代码禁止 panic」的规则。已改为 `expect()` 并附加 SAFETY 注释说明原因。

### 3. bee_router — 未使用的 `query_map` 字段

**文件：** `crates/bee_router/src/context.rs:22`
**严重程度：** 低

`query_map: HashMap<String, String>` 字段声明了 `#[allow(dead_code)]` 但从未被使用。按 YAGNI 原则已移除。

### 4. bee_logs — 测试中 tracing subscriber 可重复初始化冲突

**文件：** `crates/bee_logs/src/lib.rs:100-116`
**严重程度：** 中

`test_logger_stdout` 和 `test_logger_default` 都调用 `init()`，`tracing_subscriber::try_init()` 全局只能成功一次。已用 `std::sync::Once` 确保只初始化一次，并新增 `test_level_str` 测试覆盖 `level_str()` 方法。

### 5. bee_tsdb — 3 处 `map_or` 可简化 (Clippy)

**文件：** `crates/bee_tsdb/src/lib.rs:198,199,200-203`
**严重程度：** 低

```rust
// 修复前
p.tags.get(&f.key).map_or(false, |v| v == &f.value)
// 修复后
p.tags.get(&f.key) == Some(&f.value)
```

### 6. bee_graph — `for_kv_map` 可简化为 `values()` (Clippy)

**文件：** `crates/bee_graph/src/lib.rs:241`
**严重程度：** 低

`for (_eid, edge) in emap.iter()` → `for edge in emap.values()`

### 7. bee_rust — `needless_question_mark` (Clippy)

**文件：** `crates/bee_rust/src/lib.rs:37`
**严重程度：** 低

`Ok(bee_logs::Logger::new().init()?)` → `bee_logs::Logger::new().init()`

### 8. bee_router — Filter trait 缺少文档注释

**文件：** `crates/bee_router/src/filter.rs:4`
**严重程度：** 低

已为 `Filter` trait 添加文档注释。
