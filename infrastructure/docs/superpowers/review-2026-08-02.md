## 问题清单

### 1. 🔴 根 Cargo.toml 无效配置项

**文件**: `Cargo.toml:24`  
**问题**: `[workspace.package]` 中的 `name = "bee-rust"` 是无效键，每次编译都会产生 warning：

```
warning: /home/wwwroot/bee-rust/Cargo.toml: unused manifest key: workspace.package.name
```

**修复**: 删除 `name = "bee-rust"` 行。workspace 级别的 package 不需要 name，只有各子 crate 的 `[package]` 才需要。

---

### 2. 🔴 缺少 LICENSE 文件

**问题**: 根 `Cargo.toml` 声明 `license = "Apache-2.0"`，但仓库根目录没有 `LICENSE` 文件。Apache-2.0 许可证条款要求在分发中包含许可证副本。

**修复**: 在根目录创建 `LICENSE` 文件，包含 Apache-2.0 许可证全文。

---

### 3. 🔴 Crate 许可证元数据不一致

以下 crate 缺少 `license` 字段声明（发布到 crates.io 时将显示为「无许可证」）：

| Crate | 状态 |
|-------|------|
| bee_cache | ❌ 缺少 |
| bee_cli | ❌ 缺少 |
| bee_graph | ❌ 缺少 |
| bee_kv | ❌ 缺少 |
| bee_logs | ❌ 缺少 |
| bee_rust | ❌ 缺少 |
| bee_search | ❌ 缺少 |
| bee_template | ❌ 缺少 |
| bee_tsdb | ❌ 缺少 |

已正确声明的 crate：bee_router、bee_config、bee_session、bee_orm、bee_orm_macro

**修复**: 为上述 9 个 crate 的 `Cargo.toml` 添加 `license.workspace = true`。

---

### 4. 🟡 缺少 crates.io 发布元数据

所有 crate 缺少以下字段，不利于在 crates.io 上的可发现性：

- `description` — 简要描述
- `repository` — 代码仓库链接
- `keywords` — 搜索关键词
- `categories` — 分类（如 `["web-programming", "database"]`）

建议在 `[workspace.package]` 中添加公共字段：

```toml
[workspace.package]
repository = "https://github.com/erikwang2013/bee-rust"
keywords = ["web", "framework", "beego", "mvc"]
categories = ["web-programming"]
```

### 6. 🟡 存储引擎 Feature 为空白占位

以下 feature 已声明但无实际实现，仅为空占位符：

- `bee_search`: `elasticsearch`、`opensearch`、`clickhouse` 均为 `[]`
- `bee_graph`: `neo4j`、`nebulagraph`、`arangodb` 均为 `[]`
- `bee_tsdb`: `influxdb`、`iotdb`、`questdb` 均为 `[]`

这意味着 README 中展示的搜索引擎、图数据库、时序数据库的代码示例无法实际运行（它们测试用的也是 stub）。

**建议**: 在 README 中标注这些功能为「计划中 / planned」，或添加实际的驱动依赖和实现。

---

### 7. 🟡 StubKvStore::expire() 是空操作

**文件**: `crates/bee_kv/src/lib.rs:111`  
**问题**: 测试桩 `StubKvStore` 的 `expire()` 方法不实现 TTL 过期逻辑，但 trait 定义了该接口。这意味着测试无法覆盖 TTL 相关行为。

---

### 8. 🟢 RedisStore 多余的 cfg 注解

**文件**: `crates/bee_kv/src/redis_store.rs`  
**问题**: 整个模块已在 `lib.rs` 中通过 `#[cfg(feature = "redis")]` 条件编译，`redis_store.rs` 中的 `#[cfg(feature = "redis")]` 注解是冗余的（功能正确，但不简洁）。

---

### 9. 🟢 缺少 Doc-tests

除了 `bee_template` 有 1 个 doc-test，其余所有 crate 都没有文档测试。建议为核心 trait（`Cache`、`KvStore`、`Controller` 等）添加 doc-test 示例。

---

### 10. 🟢 bee_graph/src/lib.rs 文件偏大

406 行，接近 500 行限制。建议后续拆分（如单独的 model.rs、query.rs）。
