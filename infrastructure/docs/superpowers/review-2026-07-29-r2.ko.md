## 1차 수정 (8건)

### 1. bee_kv — 불필요한 `mut` 키워드 (컴파일 경고)

**파일:** `crates/bee_kv/src/lib.rs:129,136,145,158`
**심각도:** 낮음

`StubKvStore`의 모든 메서드는 `&self`로 호출되므로(내부는 Mutex 사용), 테스트의 `let mut store`는 `mut`가 필요 없습니다. `let store`로 변경했습니다.

### 2. bee_router — `into_response()`의 `unwrap()`이 panic을 유발할 수 있음

**파일:** `crates/bee_router/src/context.rs:119`
**심각도:** 중간

`builder.body(...).unwrap()` — 헤더 값이 내부적으로 생성되어 잘못된 문자를 포함하지 않지만, "라이브러리 코드에서 panic 금지" 규칙을 위반합니다. 이유를 설명하는 SAFETY 주석을 붙인 `expect()`로 변경했습니다.

### 3. bee_router — 사용하지 않는 `query_map` 필드

**파일:** `crates/bee_router/src/context.rs:22`
**심각도:** 낮음

`query_map: HashMap<String, String>` 필드는 `#[allow(dead_code)]`로 선언됐지만 한 번도 사용되지 않았습니다. YAGNI 원칙에 따라 제거했습니다.

### 4. bee_logs — 테스트에서 tracing subscriber 반복 초기화 충돌

**파일:** `crates/bee_logs/src/lib.rs:100-116`
**심각도:** 중간

`test_logger_stdout`와 `test_logger_default`가 모두 `init()`을 호출하며, `tracing_subscriber::try_init()`은 전역에서 한 번만 성공할 수 있습니다. `std::sync::Once`를 사용해 한 번만 초기화되도록 하고, `level_str()` 메서드를 커버하는 `test_level_str` 테스트를 새로 추가했습니다.

### 5. bee_tsdb — `map_or` 3곳 단순화 가능 (Clippy)

**파일:** `crates/bee_tsdb/src/lib.rs:198,199,200-203`

## 2차 수정 — ABCDE 전부 처리 (5건)

### A. bee_orm — `to_sql()`의 SQL 인젝션 위험 ✅ 수정됨

**파일:** `crates/bee_orm/src/lib.rs:63`
**심각도:** 높음 (잠재적)

`to_sql()`은 원본 문자열을 SQL에 직접 이어 붙입니다. 메서드 문서 주석에 이 메서드는 디버깅과 테스트 전용이며 백엔드 드라이버는 반드시 파라미터화 쿼리를 사용해야 한다는 **Warning**을 추가했습니다.

### B. bee_config_macro — `unwrap_or`가 파싱 오류를 조용히 삼킴 ✅ 수정됨

**파일:** `crates/bee_config_macro/src/lib.rs:21-27`
**심각도:** 낮음

`unwrap_or`를 `unwrap_or_else`로 변경하고 주석을 확장: JSON이 아닌 값(예: `dev`, `localhost`)은 JSON 문자열로 올바르게 폴백되며, 오타가 있는 값(예: `8o8o`)은 문자열로 저장되어 `serde_json::from_value`가 명확한 타입 불일치 오류를 생성합니다.

### C. bee_cli — 테스트 커버리지 없음 ✅ 수정됨

**파일:** `crates/bee_cli/src/main.rs`
**심각도:** 중간

모든 하위 명령을 커버하는 CLI 인자 파싱 유닛 테스트 **9개**를 추가했습니다:

- `test_new_command` — 프로젝트 생성
- `test_generate_controller` / `test_generate_model` — 코드 생성
- `test_run_command` / `test_run_watch` — 개발 서버
- `test_migrate_up` / `test_migrate_down` — 데이터베이스 마이그레이션
- `test_pack_default_target` / `test_pack_custom_target` — 패키징 배포

### D. Router/RouteGroup 문서 주석 부족 ✅ 수정됨

**파일:** `crates/bee_router/src/router.rs:5,44`
**심각도:** 낮음

`Router`와 `RouteGroup` 구조체에 문서 주석을 추가했습니다.

### E. redis_store — MultiplexedConnection 불필요한 clone ✅ 분석됨

**파일:** `crates/bee_kv/src/redis_store.rs`
**심각도:** 낮음

분석 결과 확인: `redis::Cmd::query_async`는 `&mut` 참조가 필요하며, `self.conn.clone()`은 redis-rs crate의 표준 사용법입니다. `MultiplexedConnection::clone()`은 참조 카운트만 증가시킬 뿐 오버헤드가 극히 낮습니다. **수정 불필요.**
