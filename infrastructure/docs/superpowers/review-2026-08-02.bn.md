## সমস্যার তালিকা

### ১. 🔴 রুট Cargo.toml-এ অবৈধ কনফিগারেশন আইটেম

**ফাইল**: `Cargo.toml:24`  
**সমস্যা**: `[workspace.package]`-এ `name = "bee-rust"` একটি অবৈধ কী, যা প্রতিবার কম্পাইলে warning তৈরি করে:

```
warning: /home/wwwroot/bee-rust/Cargo.toml: unused manifest key: workspace.package.name
```

**সমাধান**: `name = "bee-rust"` লাইনটি মুছে ফেলুন। workspace-স্তরের প্যাকেজের নাম লাগে না; শুধু প্রতিটি উপ-ক্রেটের `[package]`-এ লাগে।

---

### ২. 🔴 LICENSE ফাইল অনুপস্থিত

**সমস্যা**: রুট `Cargo.toml`-এ `license = "Apache-2.0"` ঘোষিত, কিন্তু রিপোজিটরির রুটে কোনো `LICENSE` ফাইল নেই। Apache-2.0 লাইসেন্সের শর্ত বিতরণে লাইসেন্সের একটি কপি অন্তর্ভুক্ত করার দাবি করে।

**সমাধান**: রুট ডিরেক্টরিতে Apache-2.0 লাইসেন্সের পূর্ণপাঠসহ `LICENSE` ফাইল তৈরি করুন।

### ৪. 🟡 crates.io প্রকাশনা মেটাডেটা অনুপস্থিত

সব ক্রেটে নিচের ফিল্ডগুলো নেই, যা crates.io-তে খুঁজে পাওয়ার ক্ষমতা কমায়:

- `description` — সংক্ষিপ্ত বিবরণ
- `repository` — রিপোজিটরি লিংক
- `keywords` — সার্চ কীওয়ার্ড
- `categories` — বিভাগ (যেমন `["web-programming", "database"]`)

`[workspace.package]`-এ সাধারণ ফিল্ড যোগ করার সুপারিশ:

```toml
[workspace.package]
repository = "https://github.com/erikwang2013/bee-rust"
keywords = ["web", "framework", "beego", "mvc"]
categories = ["web-programming"]
```

### ৭. 🟡 StubKvStore::expire() একটি খালি অপারেশন

**ফাইল**: `crates/bee_kv/src/lib.rs:111`  
**সমস্যা**: টেস্ট স্টাব `StubKvStore`-এর `expire()` মেথড TTL মেয়াদোত্তীর্ণ লজিক বাস্তবায়ন করে না, অথচ trait এই ইন্টারফেসটি সংজ্ঞায়িত করে। অর্থাৎ টেস্ট TTL-সম্পর্কিত আচরণ কভার করতে পারে না।

### ৮. 🟢 RedisStore-এ অপ্রয়োজনীয় cfg অ্যানোটেশন

**সমস্যা**: পুরো মডিউলটি আগেই `lib.rs`-এ `#[cfg(feature = "redis")]` দিয়ে শর্তসাপেক্ষে কম্পাইল হয়; `redis_store.rs`-এর ভেতরের `#[cfg(feature = "redis")]` অ্যানোটেশনটি অপ্রয়োজনীয় (কার্যত সঠিক, তবে সংক্ষিপ্ত নয়)।
