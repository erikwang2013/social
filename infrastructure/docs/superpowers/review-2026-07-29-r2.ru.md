## Исправления первого раунда (8 пунктов)

### 1. bee_kv — лишнее ключевое слово `mut` (предупреждение компиляции)

**Файл:** `crates/bee_kv/src/lib.rs:129,136,145,158`
**Серьёзность:** низкая

Все методы `StubKvStore` вызываются через `&self` (внутри используется Mutex), поэтому `let mut store` в тестах не требует `mut`. Изменено на `let store`.

### 2. bee_router — `unwrap()` в `into_response()` может вызвать panic

**Файл:** `crates/bee_router/src/context.rs:119`
**Серьёзность:** средняя

`builder.body(...).unwrap()` — хотя значения заголовков создаются внутренне и не содержат недопустимых символов, это нарушает правило «запрет panic в коде библиотек». Заменено на `expect()` с комментарием SAFETY, объясняющим причину.

### 3. bee_router — неиспользуемое поле `query_map`

**Файл:** `crates/bee_router/src/context.rs:22`
**Серьёзность:** низкая

Поле `query_map: HashMap<String, String>` было объявлено с `#[allow(dead_code)]`, но ни разу не использовалось. Удалено по принципу YAGNI.

### 4. bee_logs — конфликт повторной инициализации tracing subscriber в тестах

**Файл:** `crates/bee_logs/src/lib.rs:100-116`
**Серьёзность:** средняя

И `test_logger_stdout`, и `test_logger_default` вызывают `init()`, а `tracing_subscriber::try_init()` глобально может успешно выполниться только один раз. Использован `std::sync::Once` для гарантии однократной инициализации, добавлен тест `test_level_str`, покрывающий метод `level_str()`.

### 5. bee_tsdb — 3 случая `map_or` можно упростить (Clippy)

**Файл:** `crates/bee_tsdb/src/lib.rs:198,199,200-203`
**Серьёзность:** низкая

```rust
// До исправления
p.tags.get(&f.key).map_or(false, |v| v == &f.value)
// После исправления
p.tags.get(&f.key) == Some(&f.value)
```

### 6. bee_graph — `for_kv_map` можно упростить до `values()` (Clippy)

**Файл:** `crates/bee_graph/src/lib.rs:241`
**Серьёзность:** низкая

`for (_eid, edge) in emap.iter()` → `for edge in emap.values()`

### 7. bee_rust — `needless_question_mark` (Clippy)

**Файл:** `crates/bee_rust/src/lib.rs:37`
**Серьёзность:** низкая

### 8. bee_router — у trait Filter нет документационных комментариев
