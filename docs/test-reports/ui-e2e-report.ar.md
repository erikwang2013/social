## نطاق الاختبار وقائمة الصفحات

يعمل كلا الخادمين الخلفيين webman كعمليات حقيقية: `admin` (:8791)، `service` (:8788، WS :8789).
يحتوي `app/view/` في الطرفين على القوالب الافتراضية فقط (`index/view.html`)، دون قوالب متعددة الصفحات التقليدية — فـ«الصفحات» الفعلية هي نقاط نهاية API،
والواجهات الأمامية للويب يحملها عملاء Flutter/HarmonyOS (`apps/` لا يحتوي واجهة ويب قابلة للتشغيل، خارج نطاق E2E).

## طريقة التشغيل

```bash
cd tests/e2e && npx playwright test          # الكل
# أو حسب الملف: admin-pages.spec.js / admin-auth.spec.js / service-journey.spec.js
```

- تجهيزة حساب الاختبار: `e2e_smoke`، كلمة المرور `ApiTest!2026` (مُدخلة مسبقًا عبر SQL، انظر `tests/api/run.php`)
- يُحل كابتشا المنزلق عبر ارتباط بيرسون بالبكسلات بين «قطعة اللغز وصورة الخلفية» (مسار تفاعل حقيقي، دون تجاوز)؛
  نوع الكابتشا عشوائي (click/rotate/slider)، ولا يُحل تلقائيًا إلا slider، لذا يعيد السكربت المحاولة بصورة جديدة حتى ينجح.

## نقاط التعطيل / قيود البيئة

1. **البحث عن منشورات 503**: `/api/v1/search/posts` يعتمد على Elasticsearch (Scout) غير المُشغَّل في هذه البيئة → يُرجع 503.
   تمر الحالة معلَّمة `blocked`؛ يلزم تشغيل ES للتحقق من النتائج.
2. **ذاكرة GD لكابتشا admin**: `GdDriver` يفكك صورًا كبيرة (خلفية 5472x3648) مع `memory_limit 128M`،
   ويوجد خطر نفاد الذاكرة (OOM) عند generate المتتالي (سبق أن انهار admin في مجموعات طويلة). التجنب: إعادة تشغيل admin قبل حالات الكابتشا،
   والتشغيل على دفعات (admin-pages / admin-auth / service منفصلة). قيد بيئة وليس عيبًا في كود الأعمال.
3. **نوع كابتشا عشوائي**: generate يختار واحدة من ثلاث؛ لا تكشف click/rotate بيانات قابلة للحل، فقط slider يمر تلقائيًا (12 محاولة كحد أقصى).
4. **كلمة مرور root فارغة لقاعدة البيانات**: بيئة الاختبار المحلية توفر MySQL بكلمة مرور root/فارغة، و`.env` الافتراضي للتطبيقين متسق.
5. **تطبيقات الهاتف apps/**: android/harmonyos/ios لا تحتوي واجهة ويب قابلة للتشغيل، ولا تدخل في E2E عبر المتصفح.

## الخلاصة

نجح تسجيل دخول admin (بما في ذلك كابتشا المنزلق) و19 نقطة نهاية إدارية، وجميع حالات service البالغة 16 حالة كاملة التدفق من جهة المستخدم؛
نقطة التعطيل الوحيدة هي عدم نشر خدمة البحث (ES)، وبقية السلاسل (التسجيل/الدخول/المنشورات/التفاعل/الإشعارات/IM/الصوت) كلها مُتحقَّق من عملها.
