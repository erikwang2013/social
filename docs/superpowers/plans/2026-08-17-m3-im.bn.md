**লক্ষ্য:** M3 P1 ডেলিভার করুন: প্রাইভেট চ্যাট + গ্রুপ চ্যাটের টেক্সট/ইমেজ মেসেজ ক্লোজড লুপ — WS গেটওয়ে (webman ws worker + ক্রস-নোড Redis pub/sub), চার-টেবিল ডেটা মডেল, WS দিয়ে লেখা / REST দিয়ে পড়া, অনলাইন ডাইরেক্ট পুশ + অফলাইন কিউ + পোলিং ফলব্যাক, তিন-প্ল্যাটফর্ম WS ক্লায়েন্ট ইন্টিগ্রেশন।

**আর্কিটেকচার:** service (webman) একটি ws worker (8789) যোগ করে, কানেকশন রেজিস্ট্রেশন Redis-এ ডাবল-রাইট করে (`ws:conn:{fd}` TTL 60s + নোড ইনডেক্স `ws:user:{uid}`) + worker-এর মেমরি Map; চ্যানেলগুলো প্রতি-ব্যবহারকারী `im:user:{uid}` ক্রস-নোড pub/sub। সব রাইট পাথ WS দিয়ে যায় (send/read/typing/recall), রিড পাথ REST দিয়ে (কনভার্সেশন/হিস্ট্রি পেজিনেশন)। ডেলিভারি: অনলাইন ডাইরেক্ট পুশ + অফলাইন কিউ `im:offline:{uid}` (cap 200) + `PushProvider` ইন্টারফেস (M3-তে NullProvider, পোলিং ফলব্যাক)। মেসেজ আইডেম্পোটেন্সি: SETNX `im:dedup:{uid}:{client_msg_id}` TTL 24h + DB ইউনিক ইনডেক্স। **im proto লাগবে না** (কোনো ক্রস-সার্ভিস কল নেই, gRPC শুধু M2-এর একটি অ্যাসেট)।

**টেক স্ট্যাক:** PHP 8.3 / webman 2.x / workerman ws / Redis (webman/redis প্লাগইন) / Eloquent / sqlite :memory: টেস্ট; Android OkHttp WebSocket + kotlinx.serialization; iOS URLSessionWebSocketTask; HarmonyOS @ohos.net.webSocket।

**নিশ্চিত সিদ্ধান্ত:** পুশ কৌশল = NullProvider + ইন-অ্যাপ নোটিফিকেশন + পোলিং ফলব্যাক (ব্যবহারকারী অনুমোদিত); ভয়েস/কল/মাল্টি-ডিভাইস মাল্টি-কানেকশন M4 পর্যন্ত স্থগিত।

- [ ] **ধাপ 2: ConnectionRegistry (লোকাল কানেকশন টেবিল + Redis রেজিস্ট্রেশন)**

স্ট্যাটিক ক্লাস। `Map<int fd, int uid>` (মেমরি) + `Map<int uid, int fd>` সিঙ্গেল-কানেকশন নীতি। মেথড:
- `attach(int $fd, int $uid)`: uid-এর আগে থেকে পুরনো fd থাকলে → কিক-আউটের জন্য পুরনো fd রিটার্ন করুন (`kicked` ফ্রেম পুশ করুন + close), তারপর নতুন fd রেজিস্টার করুন; Redis-এ `ws:conn:{fd}` = uid (EXPIRE 60) এবং `ws:user:{uid}` = এই নোডের পরিচয় লিখুন (node id `gethostname().':'.posix_getpid()` বা config-এর `im.node_id` ব্যবহার করুন, লেখার সময় EXPIRE 60)।
- `detach(int $fd)`: মেমরি থেকে সরান + Redis DEL `ws:conn:{fd}`; `ws:user:{uid}` এই নোডের দিকে ইঙ্গিত করলে DEL করুন।
- `localFd(int $uid): ?int`: মেমরি খোঁজ।
- `heartbeat(int $fd, int $uid)`: `ws:conn:{fd}` এবং `ws:user:{uid}`-এর EXPIRE নবায়ন করুন।
- Redis `support\Redis` ব্যবহার করুন (webman redis প্লাগইন, বিদ্যমান `app/queue/redis` ব্যবহার দেখুন)।

  - `ConnectionRegistry::localFd($uid)` হিট → সেই worker-এ `sendToFd` দিয়ে `{type:'message', data:{...msg ফিল্ড..., sender_id}}` পুশ করুন;
  - মিস → `Redis::publish('im:user:'.$uid, json_encode([...]))` (অন্য নোড সাবস্ক্রাইব করে লোকাল Map যাচাই করে সরাসরি পুশ করে); চ্যানেলে কেউ সাবস্ক্রাইব না করলে → `Redis::rpush('im:offline:'.$uid, $payload)` + `LTRIM` cap 200।
  - অফলাইন এনকিউর পর `PushProvider::send($uid, payload)` কল করুন (M3-তে Null নো-অপ)।

- `notifyRead(int $cid, int $uid, int $lastReadId): void`: প্রতিটি মেম্বারের চ্যানেলে publish করুন `{type:'read', data:{conversation_id,user_id,last_read_id}}` (অনলাইন পুশ, অফলাইন পার্সিস্টেন্স নেই — রিড সেমান্টিক্স DB-ভিত্তিক, রিকানেক্টে পুনরায় আনা হয়)।
- `relayTyping(int $cid, int $uid): void`: প্রতিটি মেম্বারে publish করুন `{type:'typing', data:{conversation_id,user_id}}`, শুধু `!= $uid` মেম্বারদের পুশ করুন।
