# M6c CDN 接入实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 图片/语音/后台文件接入 S3 兼容对象存储 + CDN，服务商由管理端配置管理。

**Architecture:** 新表 `erik_storage_provider`（管理端 CRUD + 激活）；PHP 侧 `Storage` 薄封装（local|s3 驱动，`aws/aws-sdk-php` S3Client，endpoint 覆盖兼容 R2/OSS/COS/B2）；Rust `VoiceStorage` 换 `object_store`；上传链路保持服务端中转 + 水印，返回绝对 CDN URL；旧文件 nginx 兼容。

**Tech Stack:** PHP 8.3 / webman v2 · `aws/aws-sdk-php` · Rust `object_store` + `mysql_async`（已有）· Flutter GetX

**Spec:** `docs/superpowers/specs/2026-08-29-cdn-design.md`（权威来源）

```php
<?php
/*
 * Copyright (c) 2026 erik <erik@erik.xyz> — https://erik.xyz
 */
declare(strict_types=1);

namespace app\common;

use Aws\S3\S3Client;
use app\model\StorageProvider;

class Storage
{
    public static function activeProvider(): StorageProvider
    {
        $p = StorageProvider::where('is_active', 1)->first();
        if (!$p) {
            throw new \RuntimeException('未配置活动的存储服务商');
        }
        return $p;
    }

    /** activate 时验签：列桶前 1 个对象，失败即抛 */
    public static function verify(StorageProvider $p): void
    {
        if ($p->driver !== 's3') {
            return;
        }
        self::client($p)->listObjectsV2(['Bucket' => $p->bucket, 'MaxKeys' => 1]);
    }

    public static function client(StorageProvider $p): S3Client
    {
        return new S3Client([
            'version' => 'latest',
            'region' => $p->region ?: 'auto',
            'endpoint' => $p->endpoint,
            'use_path_style_endpoint' => true,
            'credentials' => ['key' => $p->key, 'secret' => $p->secret],
        ]);
    }
}
```

> `use_path_style_endpoint`：统一 true 最稳（COS 需要 path-style；endpoint 已含 bucket 前缀的厂商用 path-style 也无碍）。

```php
<?php
// service/app/common/Storage.php — 版权注释同项目规范
namespace app\common;

use Aws\S3\S3Client;
use support\Redis;

class Storage
{
    private const CACHE_KEY = 'storage:active_provider';
    private const CACHE_TTL = 60;

    /** 写文件 → 返回可访问 URL（local→相对路径，s3→CDN 绝对 URL） */
    public static function put(string $key, string $bytes): string
    {
        $p = self::activeProvider();
        if ($p['driver'] === 'local') {
            $path = public_path() . '/' . $key;
            if (!is_dir(dirname($path))) {
                mkdir(dirname($path), 0755, true);
            }
            file_put_contents($path, $bytes);
            return '/' . $key;
        }
        self::client($p)->putObject(['Bucket' => $p['bucket'], 'Key' => $key, 'Body' => $bytes]);
        return rtrim($p['cdn_url'], '/') . '/' . $key;
    }

    /** 活动服务商：Redis 60s 缓存 → DB 兜底（admin 变更时清缓存） */
    private static function activeProvider(): array
    {
        $cached = Redis::get(self::CACHE_KEY);
        if (is_string($cached) && $cached !== '') {
            return json_decode($cached, true);
        }
        $row = \support\Db::table('erik_storage_provider')->where('is_active', 1)->first();
        if (!$row) {
            throw new \RuntimeException('未配置活动的存储服务商');
        }
        $p = (array) $row;
        Redis::setEx(self::CACHE_KEY, self::CACHE_TTL, json_encode($p));
        return $p;
    }

    private static function client(array $p): S3Client
    {
        return new S3Client([
            'version' => 'latest',
            'region' => $p['region'] ?: 'auto',
            'endpoint' => $p['endpoint'],
            'use_path_style_endpoint' => true,
            'credentials' => ['key' => $p['key'], 'secret' => $p['secret']],
        ]);
    }
}
```

> 核对：service 侧 DB 连接名与表前缀（`\support\Db::table(...)` 是否已带前缀、Redis 工具类入口名），以 service 现有代码用法为准。若 service 读不到 `erik_storage_provider`（不同库），在 service `config/database.php` 加同库连接。
