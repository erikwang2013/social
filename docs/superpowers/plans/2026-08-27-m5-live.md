# M5 直播实施计划（最小垂直切片）

日期：2026-08-27
设计依据：`docs/superpowers/specs/2026-08-27-m5-live-design.md`
执行顺序：T1 → T2 → T3 → T4 → T5 → T6（依赖倒序，先数据层后应用层）。

## T1 数据模型 + 配置

- `database/install.sql`：追加 `social_live_rooms` 表（见 spec §2）
- `service/config/live.php`：`LIVE_RTMP_HOST`（默认 127.0.0.1）/ `LIVE_HLS_HOST`（默认 127.0.0.1）env 读取，中文注释
- `service/app/model/LiveRoom.php`：Eloquent 模型（对照 VoiceRoom.php）
- 验收：`php -l` 通过；install.sql 语法检查（mysql client 试跑建表段可选）

## T2 LiveCenter 状态机

- `service/app/live/LiveCenter.php`：create/join/leave/close/sendDanmaku/micUp/micDown/onlineCount
- Redis 键：`live:room:{id}:online` / `live:roomuser:{uid}` / `live:room:{id}:danmaku`（List 200 上限）/ `live:room:{id}:mic`（Set 8 上限）
- 构造注入 sendFn（默认 Deliverer::pushToMember），便于单测
- 关播顺序：DB 置 0 → 广播 live_closed → 删键；join 后 TOCTOU 复核（仿 RoomCenter）
- 验收：LiveCenterTest 单测覆盖 8 场景（见 T6）

## T3 REST LiveController

- `service/app/controller/LiveController.php`：create/list/detail/close/micUp/micDown 六端点
- `service/config/route.php`：/api/v1 组内注册（AuthMiddleware 内）
- 404/403/422 错误码按 spec §3；列表含在线数（scard）；详情含麦位 + 最近弹幕
- 验收：LiveControllerTest 单测 + curl 冒烟（需服务运行）

## T4 WS 帧接入

- `service/app/ws/Envelope.php`：新增 T_LIVE_JOIN/T_LIVE_LEAVE/T_DANMAKU_SEND/T_DANMAKU/T_LIVE_MIC_UP/T_LIVE_MIC_DOWN/T_LIVE_CLOSED 常量
- `service/app/ws/ActionHandler.php`：五个 case 分发到 LiveCenter（进房/弹幕先校验房间存在与状态，失败回 T_ERROR）
- 验收：ActionHandlerTest 扩展 + WS 冒烟（进房→弹幕→上麦广播链路）

## T5 第三方管线

- `service/app/live/LiveStreamService.php`：signPushUrl/signPlayUrl 纯函数（host 来自 config/live.php）
- LiveController create/detail 返回 push_url（仅房主）/ play_url
- 验收：LiveStreamServiceTest 断言地址格式

## T6 测试 + 文档

- `service/tests/LiveCenterTest.php`（8 用例：create/join/leave/close/弹幕上限/麦位上限/关播清理/TOCTOU）、`LiveControllerTest.php`、`LiveStreamServiceTest.php`、`ActionHandlerTest` 扩展 live 帧
- `service/tests/live_e2e.php` 黑盒 E2E（REST 开播→进房→弹幕→上麦→关播链路）
- 文档：README 功能总览补充直播行、里程碑描述 M5 已交付、docs/test-reports 追加 live 结果（后续测试轮次统一出报告）
- 验收：`vendor/bin/phpunit` 全绿 + live_e2e 全绿
