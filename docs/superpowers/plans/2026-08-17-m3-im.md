# M3 IM 里程碑 Implementation Plan（P1：文本+图片消息闭环）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 M3 P1：私聊+群聊的文本/图片消息闭环 — WS 网关（webman ws worker + Redis pub/sub 跨节点）、四张表数据模型、写走 WS / 读走 REST、在线直推 + 离线队列 + 轮询降级、三端 WS 客户端接入。

**Architecture:** service（webman）新增 ws worker（8789），连接注册双写 Redis（`ws:conn:{fd}` TTL 60s + `ws:user:{uid}` 节点索引）+ worker 内存 Map；频道按用户 `im:user:{uid}` 跨节点 pub/sub。写路径全走 WS（send/read/typing/recall），读路径 REST（会话/历史分页）。投递：在线直推 + 离线队列 `im:offline:{uid}`（cap 200）+ `PushProvider` 接口（M3 用 NullProvider，轮询降级兜底）。消息幂等：SETNX `im:dedup:{uid}:{client_msg_id}` TTL 24h + DB 唯一索引。**不需要 im proto**（无跨服务调用，gRPC 仅 M2 资产）。

**Tech Stack:** PHP 8.3 / webman 2.x / workerman ws / Redis（webman/redis 插件）/ Eloquent / sqlite :memory: 测试；Android OkHttp WebSocket + kotlinx.serialization；iOS URLSessionWebSocketTask；HarmonyOS @ohos.net.webSocket。

**已确认决策：** 推送策略 = NullProvider + 应用内通知 + 轮询降级（用户已拍板）；语音/通话/多端多连接后置 M4。

- [ ] **Step 2: ConnectionRegistry（本机连接表 + Redis 注册）**

静态类。`Map<int fd, int uid>`（内存）+ `Map<int uid, int fd>` 单连接策略。方法：
- `attach(int $fd, int $uid)`：若该 uid 已有旧 fd → 返回旧 fd 供踢出（推 `kicked` 帧 + close），然后注册新 fd；Redis 写 `ws:conn:{fd}` = uid（EXPIRE 60）与 `ws:user:{uid}` = 本节点标识（node id 用 `gethostname().':'.posix_getpid()` 或 config 里 `im.node_id`，写入时 EXPIRE 60）。
- `detach(int $fd)`：内存移除 + Redis DEL `ws:conn:{fd}`；若 `ws:user:{uid}` 指向本节点则 DEL。
- `localFd(int $uid): ?int`：内存查。
- `heartbeat(int $fd, int $uid)`：续期 `ws:conn:{fd}` 与 `ws:user:{uid}` 的 EXPIRE。
- Redis 用 `support\Redis`（webman redis 插件，对照现有 `app/queue/redis` 用法）。
- 本节点标识从 `config/process.php` 的 `ws.constructor.node_id` 取（默认 `gethostname()`，可改）。

- [ ] **Step 3: WsServer（Worker handler）**

- [ ] **Step 1: Envelope（信封解析/序列化）**

入帧 JSON `{type, seq, data}`；出帧 `{type, seq?, data}`。`Envelope::decode(string $raw): ?array`（json 失败/缺 type 返回 null）；`Envelope::encode(string $type, array $data, ?int $seq=null): string`。常量：`T_SEND='send' T_ACK='ack' T_READ='read' T_TYPING='typing' T_RECALL='recall' T_PING='ping'`；`T_MESSAGE='message' T_KICKED='kicked' T_PONG='pong' T_ERROR='error'`。

- [ ] **Step 2: ActionHandler::handle(int $fd, int $uid, array $env): void**

按 `$env['type']` 分发，未知类型回 `{type:'error', data:{msg:'unknown type'}}`：
- `ping` → 回 `pong`（seq 回显）；`ConnectionRegistry::heartbeat($fd,$uid)`。
- `send` → 校验 `data.{conversation_id, client_msg_id}` 与 `content|image_url` 至少其一（缺 → error）；幂等：`Redis::set('im:dedup:'.$uid.':'.$cmid, '1', 'EX', 86400, 'NX')`，false → 查库回 `{type:'ack', data:{client_msg_id, message_id}}` 后 return；落库（`Message::create`，DB 唯一索引兜底——冲突时回 ack 用已存在 id）→ `Deliverer::deliver($msg, $uid)`（Task 5）→ 回 `{type:'ack', data:{client_msg_id, message_id}}`。
- `read` → 校验 conversation_id；`MessageRead::advance($cid,$uid,$data.last_read_id)`；`Deliverer::notifyRead($cid,$uid,$lastReadId)`。
- `typing` → `Deliverer::relayTyping($cid,$uid)`（纯转发不落库）。
- `recall` → 校验 message_id 与 sender 本人；`Message::where('id',..)->where('sender_id',$uid)->first()`，`created_at` 距今 >120s 拒绝（error）；`update(['recall_status'=>1,'recall_at'=>now])`；`Deliverer::notifyRecall($cid,$mid,$uid)`。

- [ ] **Step 1: PushProvider 接口 + NullPushProvider**

```php
interface PushProvider { public function send(int $uid, array $payload): void; }
class NullPushProvider implements PushProvider { public function send(int $uid, array $payload): void {} }
```

工厂放 Deliverer：`push()` 从 config 或静态 map 取实现（M3 固定 NullPushProvider；`ponytail: 厂商接入只需加实现类+工厂分支`）。

- [ ] **Step 2: Deliverer（跨节点投递核心）**

静态方法：
- `deliver(Message $msg, int $senderId): void`：取 `ConversationMember::where('conversation_id',$msg->conversation_id)->where('status',1)->pluck('user_id')`；对每成员：
  - `ConnectionRegistry::localFd($uid)` 命中 → 该 worker 内 `sendToFd` 推 `{type:'message', data:{...msg 字段..., sender_id}}`；
  - 未命中 → `Redis::publish('im:user:'.$uid, json_encode([...]))`（其他节点订阅后查本地 Map 直推）；无人订阅该频道 → `Redis::rpush('im:offline:'.$uid, $payload)` + `LTRIM` cap 200。
  - 离线入队后调 `PushProvider::send($uid, payload)`（M3 Null 无操作）。
  - 节点订阅管理：`bootstrap(int $workerFd)` 用 `\Workerman\Timer` 每 5s 对 `im:user:*` 差量订阅本机在线用户频道（用 `Redis::subscribe` 回调推本机 fd——对照 workerman Redis 订阅示例）。订阅回调收到 `im:user:{uid}` 消息 → `localFd($uid)` 命中则直推，否则忽略（发送者已写离线队列）。
- `notifyRead(int $cid, int $uid, int $lastReadId): void`：publish 各成员频道 `{type:'read', data:{conversation_id,user_id,last_read_id}}`（在线推送，离线不落库——已读语义以 DB 为准，重连拉取）。
- `relayTyping(int $cid, int $uid): void`：publish 各成员 `{type:'typing', data:{conversation_id,user_id}}`，成员 `!= $uid` 才推。
- `notifyRecall(int $cid, int $mid, int $uid): void`：publish `{type:'recall', data:{conversation_id,message_id,user_id}}`，离线成员同样入 `im:offline:{uid}`（撤回通知需要离线送达）。
